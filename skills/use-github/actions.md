# GitHub Actions

プッシュ時とかになんらかのScriptを走らせてくれる機能

- AIによるレビュー
- CI/CD
- DBのリモート適用

なんかはこの機能が使われてる
他にもアクション毎に環境変数を設定できたり、
uses: xxxx みたいにすると、他のサードパーティのアクションを実行することもできる（実行環境はこっち）

## セキュリティ

uses: xxxx@v3 とすると、実行するアクションのタグを指定できる。
サードパーティ側でアクションの更新があったとき、こっちで何か書き換える必要がなくなる。
ただし、もしサードパーティ側のアクションが乗っ取られたとき、サプライチェーンのようにCI実行時に悪意あるスクリプトが実行できてしまう。

なのでuses: xxxx@abc123...　のように、ハッシュでバージョンを固定するべき。
アップデート周りはdependabotあたりに任せる。
