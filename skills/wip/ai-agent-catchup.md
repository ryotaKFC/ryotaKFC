# AgentSpace

## 概要

人間tエージェントを一つのチームとして一つのワークスペースで作業できる

## Agentの課題

今のAgentの活用は単独での使用を想定して構築されてる。
個々の相棒的な使い方が多いけど、AgentSpaceはAgentをチームの1人として使える

## deepwiki

公開リポジトリのURL`github.com`を`deepwiki.com`に書き換えるだけで入れる
AIでプロダクトについての検索、相談ができる

## AgentSpace使ってみる

- 自分のAgentを登録する
- 普段のSlackみたいにチャンネル内にAIがいる感じ。メンションするとAIが反応する
- Docs = AIやみんなで継続的に更新できる共有メモや作業ページ
  - .mdとかが基本
- ファイル = ただ単にチャットに添付するファイル
  - 画像とか動画見たいなバイナリファイルも送れる
- かなりSlackに近いかも
- Claudeのサブスクで動かすのは厳しそう
- タスク機能が統合されてる
  - AIメンションしてxxタスクを作ってみたいな感じで自然言語でタスクを登録できる
- AIの承認まちも統合されてる
