# cloud watch log

アプリ側のログをAWS側で取得する仕組み

```python
print("aaa")
```

とか普通にログを出すとcloude watch側で拾ってくれる
ちゃんと扱うにはMetric filterとか使う

## Metric

ログ=メトリクス ではない
ログは文章やイベントが一行ずつ記録されたもの
メトリクスログを時系列の数値にしたもの
Cloud Watchでアラートが出せるのはメトリクスに変換してから
もしエラーが出たら発火させたい場合、メトリクスに変換後、1以上で通知みたいに設定する

## chat bot

cloude watchのアラートで発火されたエラー通知をチャットツールで受け取れる & 簡単なコマンドも実行できる。
chat bot自体はメトリクスで発火されるため、チャットツールにエラーメッセージをそのまま送ることは本来できないが、
コマンドを実行することでチャットツール側でもエラーメッセージが確認できる
(SlackだとChat Botからのメッセージにエラー詳細取得するコマンドボタンがある)
