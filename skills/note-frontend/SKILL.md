## npmのサプライチェーン攻撃対策

- **サプライチェーン攻撃とは**: 攻撃者が既存のライブラリを乗っ取り、悪意あるプログラムを含んだアップデートを配信する攻撃。`npm i` した時に悪意あるコードが混入する可能性がある

### minimum release age 設定

- npm側で `minimum release age` を設定できる
- 設定した時間を経過したアップデートのみをローカルに取り込む仕組み
- 前提: サプライチェーン攻撃が起きても数時間以内には対処されること
- トレードオフ: 脆弱性パッチの適用も遅れてしまう
- 対策: Dependabot 等と併用し、脆弱性対応の遅れを補う
